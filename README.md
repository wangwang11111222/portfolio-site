# Portfolio Site

A single-page static portfolio site, built with hand-written HTML and CSS and intended
for GitHub Pages. It presents twelve curated project repositories across compilers,
GPU/HPC systems, distributed systems, and quantitative research, plus a small gallery
of result images.

## Key Features

- **No build step and no dependencies** — one `index.html`, one stylesheet, and three
  images; nothing to install or compile.
- **Twelve project cards** grouped into "Systems And Compiler Projects" and
  "Quant And Data Systems", each with a short description and technology tags.
- **Selected Outputs** section showing sample charts from the quant repositories.
- **Repository Hygiene** section describing how the public repositories are curated.
- **Responsive layout** with semantic HTML and accessibility attributes.

## Usage

Open the page directly:

```bash
# macOS/Linux
open index.html

# Windows
start index.html
```

Or serve it locally:

```bash
python -m http.server 8000
# then browse to http://localhost:8000
```

## Deployment

To publish with GitHub Pages, push the contents of this folder to the repository root
of a Pages-enabled repository (for a user site, name the repository
`<username>.github.io`) and enable Pages for the default branch. No build or CI step is
required.

## Dependencies

None. The site is plain HTML and CSS with no JavaScript, frameworks, or external
assets.

## Notes

- Project descriptions and links in `index.html` must be updated by hand when the
  linked repositories change.
- The images in `assets/` are copies of charts produced by the quant repositories; they
  are static snapshots and are not regenerated by this repository.
